Taste is the moat.

A living page about design trends, component libraries, ASCII systems, and asset workflows — built in Grainwave so the medium is the message. Custom visuals. Locked tokens. Human finish.

Custom visuals

The unfair advantage. This hero is CSS-drawn hills and a lonely cabin — not a Midjourney blob, not Unsplash. Count them: craft has 15, slop has 0.

Tokens first

Cobalt, viridian, terracotta, cream, coral. Instrument Serif + DM Sans + JetBrains Mono. Radius 0. Libraries implement the system — never the reverse.

Details are everything

Film grain overlay. Half-tone dots. Hard coral CTA pill. Sparse chrome over full-bleed art. The “small” things that models skip.

05 · Neo-brutalism · live components

Hard shadow. Zero blur.

Not soft “brutalism.” Offset shadows with no blur, thick black borders, physical press states. Good for indie shout; wrong for high-trust finance.

Ship louder

Interactive demo — hover and press the buttons. Shadow grows / shrinks like a physical object.

CSS formula

box-shadow: 4px 4px 0 #000;
border: 3px solid #000;
/* no blur · no gradient · no alpha */

When to use

Indie tools, creator platforms, playful MVPs. Skip for banking and healthcare — bold borders can burn trust.

07 · Component libraries

Headless + one expressive layer.

Distinctiveness isn’t a secret kit. Own tokens, pick one aesthetic, add at most one motion registry. Stacking Magic + Aceternity + React Bits is the new slop.

08 · Asset tools & workflows

Specialize the models.

Midjourney for art direction. Recraft for SVG icons. Ideogram for text-in-image. Rive/GSAP for motion. Never one model for everything.

01 · IMAGE

MJ / Flux

Style-lock with --sref. Series of 12. Graphic not photoreal for Grainwave.

02 · VECTOR

Recraft

Native SVG icon sets. Consistent stroke. Phosphor if you need a pack fast.

03 · FINISH

PS / grain

Half-tone, film grain, crop for negative space where type lives.

04 · MOTION

Budget 2

Rive state machines · GSAP scroll · CSS staggers. Not motion wallpaper.

05 · CODE

Agent + review

design.md + bans + high reasoning. Then design-review pass.

Prompt texture that fights slop

heavy film grain, coarse half-tone dither, risograph print texture, limited flat saturated palette (cobalt, viridian, terracotta), lonely landmark in vast landscape, editorial poster composition, graphic not photoreal — avoid: soft gradients, glassmorphism, purple

09 · Ship checklist

Screenshot tests. Pass or revise.

Click each line when true for your next build. Zero custom visuals = fail. Looks like 10 other startups = fail.

  • Remove the logo — does the page still feel like a specific brand?
  • Custom product-relevant visuals ≥ 1 (this page: cabin landscape + ASCII + neo panel)
  • Hierarchy works in grayscale (type + contrast, not color alone)
  • You can name the typefaces without looking (not “Inter and something”)
  • One clear primary action above the fold
  • Motion respects prefers-reduced-motion
  • Mobile looks intentional — not a broken desktop constraint
  • Positive + negative references fed to the agent before generation
