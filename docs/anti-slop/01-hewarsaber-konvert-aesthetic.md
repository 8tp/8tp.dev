## Aesthetic vocabulary (for prompts & skills)

### Named styles he uses

| Name | Description |
|------|-------------|
| **Grainwave** | Heavy film grain + coarse half-tone dither; bold graphic illustration; high chroma |
| **Vero-style heroes** | Saturated landscape integrated under sparse SaaS chrome (lonely cabin, vast hills) |
| **Odyssey** | Classical / myth illustration; blue–orange duotone; colonnades, silhouettes |

### Prompt-ready descriptors

```
heavy film grain, coarse half-tone dither, risograph print texture,
saturated primary color blocks (electric cobalt, viridian, terracotta),
high-contrast graphic illustration, limited flat palette (not photoreal),
cinematic negative space, lonely landmark in vast landscape,
editorial poster composition, screen-print / ink-on-paper feel,
bold geometric forms, hard light, graphic-novel lighting,
minimal UI chrome over full-bleed custom art,
serif display logo (italic/script) + clean sans body,
coral/orange CTA pill on saturated field
```

### Color system (observed)

| Role | Direction |
|------|-----------|
| Sky / void | Electric cobalt / ultramarine |
| Land / form | Viridian / deep emerald, terracotta mountains |
| CTA | Coral / vermillion pill |
| Neutrals | Near-black silhouettes, cream sand, pure white type |
| Myth series | Blue–orange complementary duotone |

### Typography vibes

- Logo: elegant **serif / slightly italic script**
- Body: clean modern **sans**, restrained
- Hierarchy: large hero statement, sparse nav
- Preference: **subtle typography** over loud type stunts

### Composition patterns

1. **Full-bleed custom art is the product** — UI is thin chrome (logo, headline, CTA) on a cinematic painting  
2. **Lonely object in vast space** — cabin, Atlas under planet, warrior in colonnade  
3. **Hard color blocking** — few hues, no muddy midtones  
4. **Texture as brand** — grain/half-tone added *after* gen (human fingerprint)  
5. **Visuals explain the product** — metaphor, not decoration

## What makes his work *not* slop

| Slop default | Hewar counter |
|--------------|---------------|
| Purple-indigo gradients, abstract blobs | Locked limited palette (cobalt + viridian + terracotta) |
| Stock/AI backgrounds with no story | Narrative art that *explains* the product |
| Inter + soft card grids | Sparse chrome over full-bleed art |
| One-click MJ dump | Series discipline + PS texture + Figma layout |
| Logo on mockups | Full brand + web + product + motion |
| Photoreal mush / uncanny faces | Graphic / print aesthetic |
| Zero human fingerprint | Manual grain/half-tone, custom graphs, interactive heroes |

### Condensed formula

1. Own a **named visual language**  
2. Generate for **direction**, finish by hand  
3. Compose for **product narrative**  
4. Obsess over **small details**  
5. Ship **systems**, not screenshots  
6. Practice publicly without client constraints so taste compounds

## Steal-this process (agency quality without the agency)

```
1. Define product metaphor in one sentence
2. Lock 3–5 brand colors + display/body type
3. Generate 12-image MJ series under one style name
4. Pick 3 winners → add grain/half-tone in PS
5. Build Figma hero: art full-bleed + 1 CTA + sparse nav
6. Ship Framer or Next; one motion moment (not twenty)
7. Carry same visual language into product empty states
```

If you only internalize one thing from this account: **custom imagery + finishing details** beat every template and every default agent skin.
