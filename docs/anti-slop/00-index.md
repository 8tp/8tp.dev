# Anti-Slop Design Research Pack

**Generated:** 2026-08-04  
**Source:** Recursive X research (subagents) + @hewarsaber / konvert.design deep dive  
**Goal:** Build sites with AI that look *designed*, not generated.

---

## Why this exists

AI made “pretty” free. The default output is now recognizable as **slop**: purple gradients, Inter everywhere, glass cards, floating “Live” badges, abstract blobs, zero custom visuals.

The people winning (including [Hewar / @hewarsaber](https://x.com/hewarsaber) at [konvert.design](https://konvert.design)) share one thesis:

> **Taste is the moat.**  
> Custom visuals are the unfair advantage.  
> Foundation → system → references → build — not prompt → tweak → ship.

This pack turns that discourse into actionable reports and templates you can feed to coding agents.

## How to use with AI agents

1. **Pick one visual thesis** (don’t stack trends).  
   Examples: *Grainwave cinematic SaaS* (Hewar mode) · *Neon terminal devtool* · *Swiss editorial* · *Neo-brutal indie*
2. Fill out `skills-ready/design.md` with tokens + positive/negative refs.
3. Paste `skills-ready/frontend-aesthetics.md` into your agent system/project instructions.
4. Generate **assets first** (MJ/Flux/Recraft series) then code the site to match them.
5. Run a design-review pass: hierarchy, spacing, a11y, “does this look like 10 other landings?”
