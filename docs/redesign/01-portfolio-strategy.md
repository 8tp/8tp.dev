## Freelance / client work (Aeperion)

**Yes — feature prominently** as a dedicated case study, not GitHub card #12.

### Recommended case structure

1. Title: Aeperion storefront redesign  
2. Role: full site redesign (Shopify) for premium gaming mousepad brand  
3. Live: https://aeperion.com  
4. Before / after if screenshots exist (highly recommended for client conversion)  
5. 3–5 bullets: constraints, what you owned, craft notes (product storytelling, performance surfaces, kit/unboxing narrative, control–speed spectrum UX)  
6. No fake metrics  

If no before shots: still ship as case study with live after + process. Wayback / client archive can fill later.

**Placement:** After spotlights, before or parallel to OSS grid. Distinct visual language (case study, not star count).
